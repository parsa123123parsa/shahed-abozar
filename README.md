# shahed-abozar

این مخزن در حال حاضر فقط شامل نمونهٔ اولیهٔ رابط کاربری برای پورتال مدرسه است و با طراحی پیشنهادی در قالب HTML/CSS/JavaScript پیاده‌سازی شده است.

برای اجرای محلی:

```bash
python3 -m http.server 8000
```

سپس به آدرس زیر بروید:

```text
http://localhost:8000/
```

این نسخه به‌صورت رابط کاربری پیش‌نویس برای پنل‌های مدیر، معاون، والدین و دانش‌آموز طراحی شده است و با توجه به شرایطی که درخواست کردید، تمرکز بر ساختار، هویت مدرسه، نظم بصری، RTL، و تجربه کاربری مشابه به پورتال‌های آموزشی مدرن است.

در حال حاضر هیچ کد PHP/MySQL و یا محدودیت‌های سازگاری InfinityFree در این مخزن اعمال نشده است؛ بنابراین اگر قرار است نسخهٔ نهایی پروژه روی سرور واقعی اجرا شود، لازم است این لایهٔ رابط کاربری با ساختار بک‌اند موجود پروژه ادغام شود.
